# Mr. Peebles, M.D. (v3)

This build includes:
- Procedural multi-floor hospital (3 floors)
- Textured 3D floors/walls/ceilings
- Gritty semi-realistic sprites (gorilla arms, patients, furniture)
- Patient AI (wander, health drains, saved runs to lobby)
- Punch + grab/throw
- Destructible walls that crumble into many shards (Option A)
- HUD (timer/quota/floor) + minimap + elevator hint

## Run
```bash
python -m http.server 8000
```
Open http://localhost:8000
